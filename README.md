# RANG — Living Atlas of Indian Art

A redesigned version of an interactive Indian Art atlas, built as a standalone HTML/CSS/JavaScript project.

## Run
1. Keep `index.html`, `styles.css`, and `script.js` in the same folder.
2. Open `index.html` in Chrome/Edge.
3. Internet is required for the Google Fonts and Leaflet/OpenStreetMap map tiles.

## Included
- Interactive India map
- 18 cultural/art landmarks
- Search
- Category filters
- Clickable map markers
- Detailed dossier modal
- Previous/next navigation
- Random "Surprise me" button
- Tradition cards
- Historical timeline
- Responsive mobile layout
- No framework/build step required

## Customization
Edit the `places` array in `script.js` to replace/add your own research, images, artists and landmarks.
